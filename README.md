# Multimodal / Graph-Based Fake News Detection (FND)

This repository contains an end-to-end fake news detection pipeline that combines Transformer-based language representations (**ModernBERT**) with Graph Neural Networks (**GraphSAGE** / **GATv2**) to classify news and Reddit submissions by leveraging both content and community/author network structures.

---

## 📁 Repository Structure

```text
├── data/                       # Dataset directory (Excluded from git)
│   ├── multimodal_train.tsv
│   ├── multimodal_validate.tsv
│   ├── multimodal_test_public.tsv
│   └── processed/              # Generated by preprocessing.py
├── outputs/                    # Generated during pipeline execution
│   ├── models/                 # Saved model weights
│   ├── graphs/                 # Edge index and node mappings
│   └── embeddings/             # Extracted node feature vectors
├── src/
│   ├── dataset.py              # PyTorch Dataset for text tokenization
│   ├── preprocessing.py        # Cleans and filters raw dataset TSVs
│   ├── create_pilot_data.py    # Downsamples data for fast local testing
│   ├── train_baseline.py       # Fine-tunes ModernBERT baseline classifier
│   ├── graph_builder.py        # Constructs post-author-subreddit graph
│   ├── embedding_extraction.py # Extracts dense text representations
│   └── gnn_train.py            # Trains GraphSAGE or GATv2
├── inspect_data.py             # Quick sanity check for raw data

├── setup.bat                   # 1-click Windows setup script
└── README.md
```

## ⚙️ 1. Environment Setup

### Option A: Automatic Setup (Windows)
Double-click `setup.bat` or run:
```cmd
setup.bat
```
This automatically initializes `.venv`, installs requirements, and sets up PyTorch and PyTorch Geometric.

---

### Option B: Manual Setup (Windows / macOS / Linux)

1. **Clone the repository:**
   ```bash
   git clone https://github.com/aryanreddyb/Fake-News-Detection.git
   cd Fake-News-Detection
   ```

2. **Create and activate a virtual environment:**
   - **Windows:**
     ```cmd
     python -m venv .venv
     .venv\Scripts\activate
     ```
   - **macOS / Linux:**
     ```bash
     python3 -m venv .venv
     source .venv/bin/activate
     ```

3. **Install Core Dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Install PyTorch:**
   - **For GPU (NVIDIA CUDA 12.1+):**
     ```bash
     pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121
     ```
   - **For CPU only:**
     ```bash
     pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cpu
     ```

5. **Install PyTorch Geometric:**
   ```bash
   pip install torch_geometric
   ```

## 💾 2. Dataset Preparation

Because the raw dataset files exceed GitHub's upload limits, they are not included in the repository.

1. Ensure a folder named `data` exists in the repository root:
   ```bash
   mkdir data
   ```
2. Place the following Fakeddit dataset TSV files inside `data/`:
   - `multimodal_train.tsv`
   - `multimodal_validate.tsv`
   - `multimodal_test_public.tsv`

*(Optional)* Run a quick sanity check to verify the data files:
```bash
python inspect_data.py
```

## 🚀 3. Step-by-Step Execution Pipeline

Run these commands in order from the repository root:

### Step 1: Preprocess the Data
Cleans titles, fills missing metadata, drops empty rows, and saves the split CSVs into `data/processed/`.
```bash
python src/preprocessing.py
```

### Step 2: (Optional for Fast Testing) Create Pilot Dataset
The full dataset contains ~500,000+ posts. If testing on a laptop or CPU without a dedicated GPU, create a balanced 10,000-row pilot dataset:
```bash
python src/create_pilot_data.py
```
> **Note:** To revert back to the full dataset at any point, simply re-run `python src/preprocessing.py`.

### Step 3: Train the ModernBERT Baseline Classifier
Fine-tunes ModernBERT on post titles for binary fake news detection. Weights are saved to `outputs/models/modernbert_baseline/`.
```bash
python src/train_baseline.py
```

### Step 4: Build the Graph
Constructs a graph connecting posts sharing common authors, subreddits, or link submissions. Generates `node_mapping.csv` and `edge_index.pt` in `outputs/graphs/`.
```bash
python src/graph_builder.py
```

### Step 5: Extract Node Embeddings
Passes the text for all graph nodes through the fine-tuned model to generate 768-dimensional node embedding vectors (`outputs/embeddings/node_embeddings.pt`).
```bash
python src/embedding_extraction.py
```

### Step 6: Train the Graph Neural Network (GNN)
Trains a GNN using inductive node masks to evaluate how relational community context improves classification performance:

- **Train GraphSAGE:**
  ```bash
  python src/gnn_train.py --model graphsage
  ```

- **Train GATv2 (Graph Attention Network v2):**
  ```bash
  python src/gnn_train.py --model gatv2
  ```

The best model weights will be saved in `outputs/models/best_graphsage.pt` or `outputs/models/best_gatv2.pt`.
